# 05: 마감과 결과 공개 (관리자 득표 현황 포함)

**What to build:** 관리자는 관리 목록에서 각 투표의 득표 현황을 마감 전에도 본다. 관리자가 "되돌릴 수 없음" 확인을 거쳐 투표를 마감하면, 그 투표는 더 이상 표를 받지 않고 모든 방문자에게 결과가 공개된다. 결과는 선택지별 득표수, 비율, 막대, 최다 득표 강조로 보여준다. 스펙: `.scratch/voting-app-mvp/spec.md`. 결정 배경: ADR-0002.

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 투표 모듈의 `closePoll(pollId)`는 `closed_at`을 설정한다. 멱등이어서 이미 마감됐어도 성공으로 보고, 투표가 없으면 `투표 없음`을 반환한다. 마감을 되돌리는 경로는 두지 않는다.
- [ ] 결과 계산은 모듈 내부의 순수 함수로 둔다.
  - 비율: 소수점 첫째 자리로 반올림
  - 최다 득표: 동점이면 모두 최다로 표시
  - 0표: 총 표 수 0으로 표시되고, 비율 계산에서 0으로 나누지 않는다.
- [ ] `getPollForVoter`는 마감된 투표에만 결과를 포함한다. 결과에는 선택지별 득표수, 비율, 최다 여부, 총 표 수가 생성 순서대로 들어간다. 투표자가 투표했다면 내 선택도 함께 반환한다.
- [ ] 관리자 시점 조회(`getPollForAdmin`과 관리 목록)는 마감 여부와 관계없이 선택지별 득표 현황과 총 표 수를 포함한다.
- [ ] 관리 목록 화면:
  - 투표별 득표 현황을 보여준다.
  - 진행 중인 투표에만 마감 버튼을 보여준다.
  - 마감 전에 "마감은 되돌릴 수 없음" 확인 단계를 둔다.
- [ ] 마감 Server Action은 첫 줄에서 관리자 세션을 검증하고, 마감 후 메인 목록, 관리 목록, 해당 투표 페이지를 갱신한다.
- [ ] 마감된 `/polls/[id]` 화면:
  - 결과를 선택지 순서대로 보여준다: 득표수, 비율, 막대.
  - 최다 득표는 강조하고, 동점이면 모두 강조한다.
  - 0표면 "참여자 없음"을 보여준다.
  - 투표자가 투표했다면 내 선택도 보여준다.
  - 투표 폼은 보여주지 않는다.
  - 목록에는 `마감` 뱃지를 붙인다.
- [ ] 통합 테스트:
  - 마감 전 투표자 시점에는 결과가 없고, 관리자 시점에는 득표 현황이 있다.
  - 마감 후 투표자 시점에 결과가 있다.
  - 마감 후 `castVote`는 `마감됨`을 반환한다.
  - 비율 반올림, 동점 처리, 0표 결과를 검증한다.
  - `closePoll`의 멱등성과, 없는 투표에 대한 동작을 검증한다.
