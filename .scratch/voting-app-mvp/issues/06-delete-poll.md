# 06: 투표 삭제

**What to build:** 관리자가 관리 목록에서 "선택지와 표까지 모두 사라짐" 확인을 거쳐 투표를 삭제하면, 그 투표는 메인 목록과 관리 목록에서 즉시 사라지고 공유 링크는 "찾을 수 없음"이 된다. 관리 목록의 각 투표에서 공개 페이지로 바로 갈 수 있는 링크도 이 티켓에서 추가한다. 스펙: `.scratch/voting-app-mvp/spec.md`.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 투표 모듈의 `deletePoll(pollId)`는 투표를 하드 삭제한다. 선택지와 표는 cascade로 함께 사라진다. 멱등이어서 없는 투표를 삭제해도 성공으로 본다.
- [ ] 관리 목록 화면:
  - 각 투표에 삭제 버튼이 있고, 삭제 전에 "선택지와 표까지 모두 사라짐" 확인 단계를 둔다.
  - 각 투표에 공개 페이지(`/polls/[id]`) 링크가 있다.
- [ ] 삭제 Server Action은 첫 줄에서 관리자 세션을 검증하고, 삭제 후 메인 목록, 관리 목록, 해당 투표 페이지를 갱신한다.
- [ ] 이미 삭제된 투표를 다른 탭에서 다시 삭제하거나 마감해도 오류로 멈추지 않는다. 멱등 처리하거나 안내를 보여준다.
- [ ] 통합 테스트:
  - 표가 있는 투표를 삭제하면 이후 조회가 "없음"을 반환한다.
  - 해당 투표의 선택지와 표가 남아 있지 않다. 공개 인터페이스(조회, 다시 만든 투표의 집계)로 확인할 수 있는 범위에서 검증한다.
  - 삭제의 멱등성
  - 다른 투표에는 영향이 없다.
