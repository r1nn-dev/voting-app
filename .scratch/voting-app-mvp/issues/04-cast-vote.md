# 04: 표 던지기와 내 선택 표시

**What to build:** 투표자가 진행 중인 투표에서 선택지 하나를 골라 제출하면 "투표 완료, 당신의 선택: ○○" 화면을 본다. 같은 브라우저로 다시 들어와도 같은 화면이 보이고, 다시 투표할 수 없다. 마감 전에는 득표수나 참여자 수 같은 어떤 수치도 보이지 않는다. 스펙: `.scratch/voting-app-mvp/spec.md`. 결정 배경: ADR-0001, ADR-0005.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 투표 모듈의 `castVote(pollId, optionId, voterId)`는 성공하거나, 반환 값으로 실패 사유를 돌려준다. 사유는 `투표 없음`, `마감됨`, `이미 투표함`, `잘못된 선택지` 중 하나다.
- [ ] 표 삽입은 `closed_at IS NULL`일 때만 행을 만드는 조건부 `INSERT ... SELECT` 한 문장으로 한다. 실패 원인은 다음처럼 판별한다.
  - PK 위반 → `이미 투표함`
  - 복합 FK 위반 → `잘못된 선택지`
  - 삽입 0행 → 투표가 있으면 `마감됨`, 없으면 `투표 없음`
- [ ] `getPollForVoter`는 투표자가 이미 투표했으면 그 선택지를 함께 반환한다.
- [ ] 투표 제출 Server Action의 쿠키 처리:
  - `voter_id` 쿠키가 없으면 새 UUID로 발급한다 (httpOnly, `SameSite=Lax`, 1년).
  - 있으면 그대로 사용한다.
  - 페이지 렌더링 중에는 쿠키를 설정하지 않는다.
- [ ] `/polls/[id]` 화면:
  - 투표하지 않은 투표자에게는 단일 선택 폼을 보여준다.
  - 투표한 투표자에게는 "투표 완료, 당신의 선택: ○○"을 보여준다.
  - 선택 없이 제출하거나 실패 사유가 돌아오면 한국어 안내를 보여준다.
- [ ] 진행 중인 투표의 투표자 화면에는 선택지별 득표수, 비율, 참여자 수가 어디에도 노출되지 않는다.
- [ ] 통합 테스트:
  - 정상 투표 후 내 선택 조회
  - 같은 투표자의 두 번째 표 → `이미 투표함`
  - 다른 투표의 선택지 → `잘못된 선택지`
  - 없는 투표 → `투표 없음`
  - 마감된 투표 → `마감됨`. 테스트 준비 단계에서 DB로 직접 마감 처리해도 된다.
  - 같은 투표자가 다른 투표에는 투표 가능
  - 진행 중인 투표의 투표자 시점에 수치 필드가 없음
