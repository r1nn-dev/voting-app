# 04: 관리자 순위와 격차 그래프

**What to build:** 관리자는 관리자용 상세 화면에서 선택지를 득표순으로 정렬한 가로 막대와 순위, 표 수, 비율을 본다. 순위는 동점이면 같고, 다음 순위는 건너뛴다(1, 1, 3위). 위쪽 요약에는 총 표 수, 1위 선택지, "1위와 2위 차이 N표 (M%p)"가 있고, 1위가 동점이면 "동점"과 동점인 선택지들이 나온다. 표가 없으면 "아직 표 없음"이다. 진행 중인 투표도 같은 그래프를 득표 현황으로 보고, "마감 예정까지 N" 안내가 붙는다.

스펙: `.scratch/deadline-archive-charts/spec.md`. 결정 배경: ADR-0002.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] `getPollForAdmin`이 순위와 격차를 함께 돌려준다.
  - 선택지: 득표순으로 정렬하고, 경쟁 순위, 표 수, 비율, 1위 여부를 담는다.
  - 요약:
    - 총 표 수
    - 1위 선택지들(동점이면 여럿)과 동점 여부
    - 1위와 2위의 차이: 표 수와 %p. %p는 반올림 전 비율로 계산한 뒤 소수점 첫째 자리로 반올림한다. 1위가 동점이면 0이다.
  - 모두 0표면 1위와 격차는 "없음"이다.
- [ ] 순위와 격차 계산은 모듈 내부의 순수 함수로 두고, 기존 비율과 1위 판정을 재사용한다.
- [ ] 상세 화면:
  - 요약 영역과 득표순 가로 막대(순위 · 선택지 · 표 수 · 비율)를 보여준다. 1위는 강조한다.
  - 진행 중일 때는 "득표 현황"으로, 마감이면 "결과"로 이름을 붙인다.
  - 0표면 "아직 표 없음"을 보여준다.
- [ ] 라이브러리 없이 HTML/CSS 서버 컴포넌트로 그린다. 수치는 항상 글자로도 표시한다.
- [ ] 투표자 시점의 진행 중 투표에는 여전히 수치가 없다. 이 데이터는 관리자 화면에만 간다.
- [ ] 통합 테스트:
  - 경쟁 순위(동점 1, 1, 3)
  - 1위와 2위 차이(표와 %p)
  - 1위 동점이면 차이 0과 동점 표시
  - 0표면 1위와 격차 없음
  - 마감 전에도 관리자 시점에는 순위와 격차가 있다.
- [ ] `npm test`, `npm run typecheck`, `npm run lint`, `npm run build`가 통과한다.
