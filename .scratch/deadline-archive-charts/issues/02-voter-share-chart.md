# 02: 투표자 결과(비중) 그래프

**What to build:** 투표자는 마감된 투표에서 결과를 **비중**으로 본다. 전체를 100%로 한 누적 막대 한 줄 아래에 범례(색 · 선택지 · 비율 · 표 수)가 있다. 막대 조각과 범례는 득표순이고, 동점이면 생성 순서다. 1위(동점이면 모두)가 강조되고, 내가 고른 선택지에는 "내 선택"이 붙는다. 표가 없으면 "참여자 없음"이다. 마감 전에는 지금처럼 어떤 수치도 보이지 않는다.

스펙: `.scratch/deadline-archive-charts/spec.md`. 결정 배경: ADR-0002.

**Blocked by:** None (can start immediately). 01과 동시에 진행하면 투표자 조회 부분에서 병합 충돌을 한 번 정리해야 할 수 있다.

**Status:** ready-for-agent

- [ ] 투표자 조회의 마감된 투표 결과를 비중으로 바꾼다.
  - 선택지별 표 수, 비율(소수점 첫째 자리), 1위 여부, 내 선택 여부와 총 표 수를 담는다.
  - 정렬은 득표 내림차순이고, 동점이면 생성 순서다.
  - 비중 계산과 정렬은 모듈 내부의 순수 함수로 두고, 기존 비율과 1위 판정을 재사용한다.
- [ ] 진행 중인 투표의 투표자 조회에는 여전히 수치 필드가 없다.
- [ ] 결과 화면:
  - 100% 누적 막대 한 줄: 조각 너비는 비율이고, 선택지별 고정 색 팔레트(최대 10색)를 쓴다.
  - 막대 아래 범례: 색, 선택지, 비율, 표 수를 담는다.
  - 1위(동점이면 모두)를 강조하고, "내 선택"을 표시한다.
  - 0표면 막대 대신 "참여자 없음"을 보여준다.
- [ ] 색만으로 정보를 전달하지 않는다. 범례에 비율과 표 수가 항상 글자로 있다.
- [ ] 라이브러리 없이 HTML/CSS 서버 컴포넌트로 그리고, 다크 모드에서도 읽힌다.
- [ ] 통합 테스트:
  - 결과 순서는 득표 내림차순이고, 동점이면 생성 순서다. 기존 "생성 순서" 테스트를 바꾼다.
  - 비율 반올림, 1위 강조(동점 포함), 내 선택 여부, 0표를 검증한다.
  - 진행 중 투표자 시점에 수치가 없다.
- [ ] `npm test`, `npm run typecheck`, `npm run lint`, `npm run build`가 통과한다.
