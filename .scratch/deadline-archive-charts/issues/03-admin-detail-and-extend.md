# 03: 관리자용 투표 상세 화면과 연장

**What to build:** 관리자는 관리 목록에서 투표를 눌러 관리자용 상세 화면(`/admin/polls/[id]`)으로 간다. 상세 화면에서는 상태, 마감 예정 시각과 남은 시간(진행 중) 또는 마감 시각(마감)을 보고, 공개 페이지 링크, 마감 버튼, 삭제 버튼을 쓴다. 진행 중인 투표는 마감 예정 시각을 늦추는 방향으로 연장할 수 있다. 입력칸이나 "+1시간 / +1일 / +1주" 버튼으로 새 시각을 정하는데, 버튼은 현재 마감 예정 시각을 기준으로 더한다. 규칙을 벗어나면 이유를 안내받는다. 순위와 격차 그래프는 04에서 이 화면에 붙인다.

스펙: `.scratch/deadline-archive-charts/spec.md`. 결정 배경: ADR-0006, ADR-0002, ADR-0004.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 투표 모듈의 `extendDeadline(pollId, newDeadline)`은 성공하거나, 반환 값으로 실패 사유를 돌려준다: `not_found` / `closed` / `not_later`(현재 마감 예정 시각 이하) / `out_of_range`(지금 + 30일 초과).
- [ ] 연장은 한 문장 조건부 UPDATE로 처리한다. 조건은 진행 중이고, 새 시각이 현재보다 늦고, 새 시각이 지금 + 30일 이하인 것이다. 0행이면 원인을 판별한다. 마감과 연장이 동시에 들어와도 마감된 투표가 다시 열리지 않는다.
- [ ] 투표 모듈의 `getPollForAdmin(pollId)`는 질문, 상태(`open` / `closed`), 마감 예정 시각, 마감 시각(마감이면)을 돌려주고, 없는 투표면 "없음"을 돌려준다. 순위와 격차는 04, 보관 상태는 05에서 더한다.
- [ ] `/admin/polls/[id]` 화면:
  - 서버에서 관리자 세션을 검증한다.
  - 없는 투표면 404다.
  - 상태, 시각과 남은 시간, 공개 페이지 링크를 보여준다.
  - 진행 중일 때만 마감 버튼을 보여주고, 기존 확인 단계를 쓴다.
  - 삭제 버튼은 기존 확인 단계를 쓰고, 삭제 후 관리 목록으로 이동한다.
- [ ] 연장 영역은 진행 중일 때만 보인다.
  - 현재 마감 예정 시각을 보여준다.
  - `datetime-local` 입력(KST)과 현재 마감 예정 시각 기준 "+1시간 / +1일 / +1주" 버튼이 있다.
  - 확인 단계를 거친다.
  - 실패 사유를 한국어로 안내한다: 앞당김 / 30일 초과 / 이미 마감 / 없음
- [ ] 연장 Server Action은 첫 줄에서 관리자 세션을 검증한다. 성공하면 메인, 관리 목록, 공개 페이지, 관리자 상세 화면을 갱신하고, 실패하면 폼과 안내를 유지한다.
- [ ] 관리 목록의 각 투표가 관리자 상세 화면으로 연결된다.
- [ ] 통합 테스트는 시계를 주입해서 검증한다:
  - 연장 성공 후 투표자 시점의 마감 예정 시각이 바뀐다.
  - 원래 마감 예정 시각이 지난 뒤에도, 연장된 시각 전이면 투표할 수 있다.
  - 실패 사유: `not_later`, `out_of_range`, `closed`(직접 마감한 경우와 시각이 지난 경우 모두), `not_found`
  - `getPollForAdmin`의 상태와 시각
- [ ] `npm test`, `npm run typecheck`, `npm run lint`, `npm run build`가 통과한다.
