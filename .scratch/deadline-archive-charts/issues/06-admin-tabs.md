# 06: 관리 화면 탭 (진행 중 / 마감 / 보관)

**What to build:** 관리자는 관리 화면에서 투표를 **진행 중 / 마감 / 보관** 탭으로 나눠 본다. 탭마다 개수가 붙어 있다. 진행 중 탭은 마감 예정 시각이 가까운 순이고, 마감 탭과 보관 탭은 마감 시각 최근순이다. 마감 탭의 각 투표에는 "보관까지 N일"이 붙는다. 각 투표는 질문, 시각, 총 표 수, 현재 1위를 한 줄로 보여주고, 누르면 관리자용 상세 화면으로 간다. 보던 탭은 새로고침하거나 뒤로 가기를 해도 유지된다.

스펙: `.scratch/deadline-archive-charts/spec.md`. 결정 배경: ADR-0006.

**Blocked by:** 03, 05

**Status:** ready-for-agent

- [ ] `listPollsForAdmin()`이 `open` / `closed` / `archived` 세 묶음과 각 개수를 돌려준다.
  - 정렬: 진행 중은 마감 예정 시각 오름차순, 마감과 보관은 마감 시각 내림차순
  - 각 항목: ID, 질문, 마감 예정 시각, 마감 시각, 총 표 수, 1위 선택지(동점이면 여럿, 0표면 없음)
- [ ] 탭은 `?tab=open|closed|archived` 쿼리로 구분한다. 기본값은 `open`이고, 알 수 없는 값도 `open`으로 본다. Next 16에서 `searchParams`는 Promise다.
- [ ] 탭 헤더에 각 탭의 개수를 보여주고, 현재 탭을 표시한다.
- [ ] 목록 한 줄:
  - 질문, 시각(진행 중이면 마감 예정 시각과 남은 시간, 마감과 보관이면 마감 시각), 총 표 수, 현재 1위(0표면 "표 없음")를 보여준다.
  - 마감 탭에는 "보관까지 N일"을 붙인다.
  - 누르면 관리자용 상세 화면으로 간다.
- [ ] 빈 탭에는 "없음" 안내를 보여준다.
- [ ] 기존 관리 목록의 인라인 막대, 마감 버튼, 삭제 버튼은 상세 화면(03)으로 옮기고, 목록은 요약 한 줄로 줄인다. "새 투표"와 "로그아웃"은 그대로 둔다.
- [ ] 통합 테스트는 시계를 주입해서 검증한다:
  - 세 묶음의 분류와 개수
  - 묶음별 정렬
  - 1위 요약(동점, 0표)
- [ ] `npm test`, `npm run typecheck`, `npm run lint`, `npm run build`가 통과한다.
