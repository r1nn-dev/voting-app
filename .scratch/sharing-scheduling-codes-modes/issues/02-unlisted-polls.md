# 02: 링크 전용 투표

**What to build:** 관리자가 투표를 만들 때 **목록 공개** 또는 **링크 전용**을 고르고, 상세 화면에서 언제든 바꾼다. 링크 전용 투표는 진행 중이든 마감이든 메인 목록에 나오지 않고, 링크를 가진 사람은 평소처럼 투표하고 결과를 본다. 관리 목록과 상세 화면에는 "링크 전용" 뱃지가 붙는다. 스펙: `.scratch/sharing-scheduling-codes-modes/spec.md`. 용어: `CONTEXT.md`의 목록 공개 / 링크 전용.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 새 마이그레이션이 `polls.listed`(boolean, NOT NULL, 기본 true)를 추가한다. 기존 투표는 모두 목록 공개가 된다.
- [ ] `createPoll`이 `listed`를 받는다(기본 true).
- [ ] 투표 모듈의 `setListed(pollId, listed)`는 상태와 관계없이 동작하고, 없는 투표면 `not_found`를 돌려준다.
- [ ] `listPolls`(메인)는 링크 전용 투표를 모든 구역에서 뺀다. 투표자 조회와 관리자 조회는 공개 방식과 관계없이 동작한다. 관리 목록 항목과 관리자 조회에 공개 방식을 담는다.
- [ ] 새 투표 폼에 공개 방식 선택(기본: 목록 공개)과 "링크 전용은 목록에 나오지 않고 링크를 가진 사람만 들어옵니다" 안내가 있다.
- [ ] 관리자 상세 화면에 공개 방식 전환이 있다. 전환 Server Action은 첫 줄에서 관리자 세션을 검증하고, 메인·관리 목록·상세를 갱신한다.
- [ ] 관리 목록과 상세 화면에 "링크 전용" 뱃지를 붙인다.
- [ ] 시드에 링크 전용 예시 1개를 추가한다.
- [ ] 도움말에 "목록에 나오지 않고 링크로만 들어오는 투표도 있습니다" 한 줄을 추가한다. 관리 기능은 설명하지 않는다.
- [ ] 통합 테스트:
  - 링크 전용 투표는 메인 목록의 진행 중·마감 구역 어디에도 없다.
  - 투표자 조회로는 보이고 투표할 수 있다.
  - 관리 목록에는 있다.
  - `setListed` 전환이 즉시 반영된다. 없는 투표면 `not_found`.
- [ ] `npm test`, `npm run typecheck`, `npm run lint`, `npm run build`가 통과한다.
