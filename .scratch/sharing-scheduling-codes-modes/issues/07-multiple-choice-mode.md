# 07: 복수 선택 모드

**What to build:** 관리자가 투표를 만들 때 **단일 선택** 또는 **복수 선택**을 고르고, 복수 선택이면 **최대 선택 수**(2~선택지 개수, 기본은 전부)를 정한다. 모드와 최대 선택 수는 만든 뒤 바꿀 수 없다. 투표자는 복수 선택 투표에서 체크박스 카드로 1개부터 최대 개수까지 고르고, "최대 N개 · 지금 M개 선택"을 본다. 완료 화면에는 고른 것을 모두 보여준다. 결과는 선택지별 가로 막대와 "표 중 N%"로 보여주고, 비율 합이 100%를 넘는다는 안내를 붙인다. 관리자의 순위와 격차는 표 대비 %p로 계산한다. 스펙: `.scratch/sharing-scheduling-codes-modes/spec.md`. 결정 배경: ADR-0008. 용어: `CONTEXT.md`의 표, 결과, 투표 모드, 최대 선택 수.

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 새 마이그레이션이 `polls.mode`(`single` | `multiple`, 기본 `single`)와 `polls.max_choices`(복수 선택일 때만, 2 이상, 선택지 개수 이하)를 추가한다. 기존 투표는 단일 선택이다.
- [ ] `createPoll`이 `mode`와 `maxChoices`를 받아 검증한다. 복수 선택에서 `maxChoices`를 주지 않으면 선택지 개수다. 단일 선택에서 `maxChoices`를 주면 오류다.
- [ ] `castVote`의 `invalid_choice` 검사를 모드에 맞춘다. 단일 선택은 정확히 1개, 복수 선택은 1개 이상 최대 선택 수 이하다. 검사는 저장 문장 안에서 하고, 앱 코드 검증은 안내용이다.
- [ ] 결과 계산:
  - 단일 선택은 지금의 비중(합 100%)을 유지한다.
  - 복수 선택은 선택지별 "그 선택지를 담은 표 수 ÷ 전체 표 수"다(합이 100%를 넘을 수 있다).
  - 1위(동점 포함)와 내 선택 표시는 두 모드에 공통이다.
- [ ] 관리자 순위와 격차는 표 대비 비율과 %p로 계산한다. 단일 선택에서는 지금과 같은 값이다.
- [ ] 투표자 조회, 관리자 조회, 관리 목록 항목에 모드와 최대 선택 수를 담는다. 복제용 설정과 결과 CSV에 모드를 추가한다.
- [ ] 화면:
  - 새 투표 폼에 투표 모드 선택과 최대 선택 수(복수 선택일 때만)를 둔다.
  - 복수 선택 투표 폼: 체크박스 카드와 "최대 N개 · 지금 M개 선택". 최대에 도달하면 나머지를 비활성화하고, 0개면 제출할 수 없다.
  - 완료 화면에 "당신의 선택: A, B"를 보여준다.
  - 복수 선택 결과: 선택지별 가로 막대(표 대비 %)와 "한 표에 여러 개를 고를 수 있어 비율 합이 100%를 넘을 수 있습니다" 안내
  - 관리 목록과 상세에 "복수 선택 · 최대 N개" 표시
- [ ] 시드에 복수 선택 예시 1개(표 포함, 마감)를 추가한다. 도움말에 복수 선택 투표와 결과 읽는 법을 추가한다.
- [ ] 통합 테스트:
  - 복수 선택 표 저장, `myChoices` 여러 개
  - 0개, 최대 초과, 중복 선택지, 다른 투표의 선택지를 `invalid_choice`로 거부
  - 단일 선택에서 2개 거부
  - 생성 검증(최대 선택 수 범위, 단일 선택에 최대 선택 수)
  - 복수 선택 비율이 표 대비(합 100% 초과), 1위 동점
  - 순위와 격차가 표 대비 %p
  - CSV와 복제용 설정에 모드
- [ ] `npm test`, `npm run typecheck`, `npm run lint`, `npm run build`가 통과한다.
