# 03: 결과 CSV 내보내기와 투표 복제

**What to build:** 관리자가 상세 화면에서 결과 CSV를 받는다. 마감 전이면 득표 현황이 담기고, 엑셀에서 열어도 한글이 깨지지 않는다. "복제"를 누르면 새 투표 폼이 질문, 선택지(순서 그대로), 공개 방식으로 미리 채워져 열리고, 관리자는 시각을 새로 정해 만든다. 표는 복사되지 않는다. 스펙: `.scratch/sharing-scheduling-codes-modes/spec.md`.

**Blocked by:** 02 (복제가 공개 방식을 복사한다)

**Status:** ready-for-agent

- [ ] 투표 모듈의 `resultsCsv(pollId)`는 UTF-8 BOM으로 시작하는 CSV 문자열을 돌려주고, 없는 투표면 "없음"을 돌려준다.
  - 투표 정보 줄: 질문, 상태, 마감 예정 시각, 마감 시각, 총 표 수(KST 표기)
  - 선택지별 줄: 순위, 선택지, 표 수, 비율(득표순)
  - 쉼표, 따옴표, 줄바꿈이 들어간 값은 CSV 규칙대로 이스케이프한다.
  - 투표자 식별 값은 담지 않는다.
- [ ] 결과 CSV 다운로드는 관리자 전용 Route Handler다. 첫 줄에서 세션을 검증하고, 파일 이름(`한표-결과-<질문 앞부분>.csv` 등)을 `Content-Disposition`으로 지정한다. 상태와 관계없이 받을 수 있다.
- [ ] 관리자 조회가 복제용 설정(질문, 선택지 순서, 공개 방식)을 돌려준다.
- [ ] 상세 화면의 "복제"는 새 투표 폼을 `?from=<id>`로 연다. 폼 페이지는 서버에서 복제용 설정을 읽어 초기값으로 넘긴다. 없는 ID면 빈 폼을 연다. 시각은 기본값(지금 + 24시간)을 쓰고, 복제됐다는 안내를 보여준다.
- [ ] 상세 화면에 "결과 CSV 받기"와 "복제" 버튼이 있다.
- [ ] 통합 테스트:
  - 결과 CSV의 BOM, 줄 구성, 득표순 정렬
  - 쉼표와 따옴표가 든 선택지의 이스케이프
  - 투표자 식별 값 없음
  - 마감 전에도 생성된다.
  - 복제용 설정의 질문, 선택지 순서, 공개 방식
- [ ] `npm test`, `npm run typecheck`, `npm run lint`, `npm run build`가 통과한다.
