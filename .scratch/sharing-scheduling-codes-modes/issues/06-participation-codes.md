# 06: 참여 코드

**What to build:** 관리자가 투표를 만들 때 **참여 코드**를 켜고 개수(1~500)를 정한다. 발급된 8자리 1회용 코드를 한 사람에게 하나씩 나눠 주면, 코드 하나로 표를 한 번만 던질 수 있다. 투표자는 투표 페이지의 코드 입력칸에 코드를 넣고 투표한다. 개인 링크(`?code=`)로 들어오면 코드가 미리 채워진다. 한 기기로 여러 사람이 각자 코드를 넣고 투표할 수 있어서, 완료 화면에 "다른 코드로 투표하기"가 있다. 관리자는 "코드 N개 중 M개 사용"을 보고, 코드를 추가로 발급하고, 코드 목록 CSV(개인 링크 포함)를 받는다. 어떤 코드로 어떤 선택을 했는지는 남지 않는다. 스펙: `.scratch/sharing-scheduling-codes-modes/spec.md`. 결정 배경: ADR-0007.

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 새 마이그레이션이 `polls.uses_codes`(기본 false)와 참여 코드 테이블(투표, 코드, 사용 시각)을 추가한다. (투표, 코드)는 유일하다. 표와 연결하는 열은 두지 않는다.
- [ ] 코드 형식은 8자리이고 헷갈리는 글자(0, O, 1, I, L)를 뺀 대문자·숫자로 만든다. 암호학적 난수로 생성하고, 한 투표 안에서 중복되지 않게 한다.
- [ ] `createPoll`이 `codeCount`(0이면 코드 없음, 1~500)를 받아, 투표와 코드를 함께 만든다.
- [ ] `issueCodes(pollId, count)`는 코드를 쓰는 투표이고 시작 전이나 진행 중일 때만 동작하며, 총 500개를 넘지 않는다. 실패 사유는 `not_found` / `codes_disabled` / `closed` / `limit_exceeded`.
- [ ] `castVote(pollId, optionIds[], voterId, code?)`
  - 코드 투표에서는 "미사용 코드를 사용 처리"와 "표 저장"을 한 문장(CTE)으로 한다. 사용 처리가 됐을 때만 표가 들어가고, 표는 코드 투표 여부만 표시한다.
  - 코드 없음, 없는 코드, 이미 쓴 코드, 다른 투표의 코드는 모두 `invalid_code` 하나로 거부한다.
  - 코드는 앞뒤 공백을 지우고 대문자로 바꿔 비교한다.
  - 코드 투표에는 브라우저당 한 표 제한이 없다. 코드 없는 투표는 지금처럼 브라우저당 한 표다.
- [ ] 투표자 조회에 코드 필요 여부를 담는다. 코드 투표의 `myChoices`는 그 브라우저의 마지막 표 기준이다.
- [ ] 관리자 조회에 코드 통계(발급 수, 사용 수)를 담는다. 복제용 설정에 코드 사용 여부를 추가한다(코드는 복사하지 않는다).
- [ ] `codesCsv(pollId, baseUrl)`는 BOM, 코드, 사용 여부, 개인 링크(`<baseUrl>/polls/<id>?code=<코드>`)를 담는다. 다운로드는 관리자 전용 Route Handler이고 첫 줄에서 세션을 검증한다.
- [ ] 화면:
  - 새 투표 폼에 "참여 코드 사용"과 개수를 둔다.
  - 투표 페이지에 코드 입력칸(`?code=`로 미리 채움), 실패 안내 "사용할 수 없는 코드입니다", 완료 화면의 "다른 코드로 투표하기"(코드 입력칸이 빈 투표 화면으로 돌아감)를 둔다.
  - 관리자 상세에 사용 현황, 추가 발급(첫 줄에서 세션 검증, 투표 ID는 숨은 입력값), 코드 CSV 받기를 둔다.
- [ ] 시드에 코드 투표 예시 1개(코드 일부 사용)를 추가한다.
- [ ] 도움말에 코드 입력 방법을 추가하고, 약관에 "받은 코드를 다른 사람에게 넘겨 대신 투표하게 하는 것은 코드를 받은 사람의 책임"을 추가한다. 관리 기능은 설명하지 않는다.
- [ ] 통합 테스트:
  - 발급 개수, 형식(길이, 제외 글자), 한 투표 안의 중복 없음
  - 추가 발급과 500개 상한, `codes_disabled`, 마감 후 `closed`
  - 코드로 투표 성공
  - 같은 코드 재사용, 없는 코드, 다른 투표의 코드, 코드 누락을 모두 `invalid_code`로 거부
  - 소문자와 공백 정규화
  - 같은 투표자 ID로도 코드가 다르면 여러 표, 사용 수 집계
  - 코드 없는 투표는 여전히 브라우저당 한 표
  - 코드 CSV의 개인 링크
- [ ] `npm test`, `npm run typecheck`, `npm run lint`, `npm run build`가 통과한다.
