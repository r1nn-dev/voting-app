# 01: 공유 버튼과 QR

**What to build:** 투표자와 관리자가 투표 페이지와 관리자 상세 화면에서 "링크 복사"를 눌러 투표 주소를 복사하고, QR 코드를 펼쳐 옆 사람이 휴대폰 카메라로 바로 들어오게 한다. 관리자는 "QR 크게 보기"로 질문, 큰 QR, 짧은 주소, 남은 시간(시작 전이면 시작 시각)만 담긴 전체 화면을 프로젝터에 띄운다. 공유 주소는 항상 운영 사이트 주소이고, 공개 기간이 끝난 투표에는 공유 수단이 보이지 않는다. DB는 바꾸지 않는다. 스펙: `.scratch/sharing-scheduling-codes-modes/spec.md`.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 절대 주소는 환경변수 `SITE_URL`을 기준으로 만든다. 없으면 요청 헤더의 호스트로 대체한다. 두 경우 모두 `/polls/[id]` 경로를 붙인다.
- [ ] "링크 복사"는 클라이언트 클립보드 API로 복사하고, 성공하면 "복사됨" 안내를 잠깐 보여준다. 실패하면 주소를 선택할 수 있는 텍스트로 보여준다.
- [ ] QR은 `qrcode` 라이브러리로 서버에서 SVG를 만든다. 외부 QR 서비스는 쓰지 않는다.
- [ ] 투표 페이지(진행 중, 마감)에 링크 복사와 QR 보기가 있다. 보관 안내 화면에는 없다.
- [ ] 관리자 상세 화면에 링크 복사, QR, "QR 크게 보기"가 있다. 보관된 투표에서는 공유 수단을 숨긴다.
- [ ] "QR 크게 보기"는 관리자 전용 경로로, 서버에서 관리자 세션을 검증한다. 질문, 화면 높이에 맞춘 QR, 짧은 주소, 남은 시간을 보여준다. 헤더와 푸터 없이 전체 화면에 맞게 배치하고, 상세 화면으로 돌아가는 링크를 둔다.
- [ ] README 환경변수 표에 `SITE_URL`(운영 주소, 예: `https://…vercel.app`)을 추가한다.
- [ ] `npm test`, `npm run typecheck`, `npm run lint`, `npm run build`가 통과한다.
