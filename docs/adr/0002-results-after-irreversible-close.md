# 결과는 마감 후에만 공개하고, 마감은 되돌릴 수 없다

앞선 결과를 보고 따라 찍는 것을 막기 위해, 일반 사용자에게는 관리자가 마감한 뒤에만 결과를 보여준다. 마감 전에는 참여자 수도 숨긴다. 마감을 되돌릴 수 있게 하면 결과를 본 사람들이 이어서 투표하게 되므로, 상태는 `open → closed` 한 방향만 허용한다. 그래서 상태 컬럼 대신 `polls.closed_at`(NULL이면 진행 중)만 둔다. 관리자는 마감 시점을 판단할 수 있도록 마감 전에도 득표 현황을 본다. 잘못 마감했다면 삭제하고 다시 만든다.

## 갱신 (ADR-0006)

이제 마감은 관리자가 직접 할 수도 있고, 마감 예정 시각이 지나서 일어날 수도 있다. 그래서 "`closed_at`이 NULL이면 진행 중"은 더 이상 맞지 않는다. `closed_at`은 관리자가 직접 마감한 시각만 뜻하고, 마감 여부는 ADR-0006의 판정식을 따른다. 결과는 마감 후에만 공개하고 마감은 되돌릴 수 없다는 이 ADR의 결정은 그대로 유지한다. 연장도 진행 중인 투표에만 허용하므로, 마감된 투표를 다시 여는 수단이 되지 않는다.
