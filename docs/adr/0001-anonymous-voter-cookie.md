# 투표자는 로그인 없이 쿠키로 식별한다

투표자 로그인은 "간단한 앱"의 범위를 넘고, IP 기준 식별은 같은 네트워크(학교, 회사)의 사람들을 막는다. 그래서 첫 투표 시 Server Action에서 `voter_id`(UUID, httpOnly, `SameSite=Lax`, 1년) 쿠키를 발급하고, "한 표"를 "한 브라우저당 한 표"로 정의했다. 시크릿 창이나 쿠키 삭제로 중복 투표가 가능하다는 한계는 수십~수백 명 규모에서 알고 수용한 것이다. 강한 중복 방지가 필요해지면 이 결정을 다시 봐야 한다.
